# Security Policy

## Supported versions

Until AI-Enabled Contracts Lab reaches a stable release, security fixes are made on the
default branch and included in the next tagged release.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** private security advisory feature. Do
not open a public issue for an unpatched vulnerability and do not attach private
contracts, API keys, tokens, or personal data.

Include the affected version, reproduction steps using synthetic data, expected
impact, and any suggested mitigation. The maintainer should acknowledge a valid
report within seven days and coordinate disclosure after a fix is available.

## Scope reminders

AI-Enabled Contracts Lab is local educational software, not legal advice. W&B integration is
optional, and users are responsible for reviewing what leaves their computer.
Model files and third-party datasets retain their own licenses and security
considerations.
