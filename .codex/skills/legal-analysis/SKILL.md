# Structured Legal Analysis Skill

For every identified issue:
1. State the issue.
2. State the general rule/elements.
3. Identify supporting facts.
4. Identify adverse facts.
5. Identify missing facts.
6. Apply facts element by element.
7. Identify defenses and counterarguments.
8. State jurisdiction limitations.
9. Give a bounded conclusion.

If jurisdiction-specific law is required but not verified, emit:
`JURISDICTION_SPECIFIC_VERIFICATION_REQUIRED`.

Never fabricate cases, statutes, regulations, or citations.
